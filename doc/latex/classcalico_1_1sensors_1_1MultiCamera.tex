Compute synthetic camera measurements given a \mbox{\hyperlink{classcalico_1_1Trajectory}{Trajectory}} and \mbox{\hyperlink{classcalico_1_1WorldModel}{World\+Model}}. This method projects the world model through the kinematic chain at given timestamps. This method returns only valid synthetic measurements as would be observed by the actual sensor, complying with physicality such as features being in front of the camera. Returns measurements in the order of the interpolation timestamps.~\newline
~\newline
{\ttfamily interp\+\_\+times} is a vector of timestamps in seconds at which {\ttfamily sensorrig\+\_\+trajectory} will be interpolated. No assumptions are made about timestamp uniqueness or order.~\newline
~\newline
